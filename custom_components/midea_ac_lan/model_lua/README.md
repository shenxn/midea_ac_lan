# Lua helpers

`bit.lua` and `cjson.lua` retain the copyright and MIT license notices embedded
in their source. The latter provides the `cjson` module name expected by the
vendor scripts using rxi's JSON implementation.

Vendor `T_*.lua` files are deliberately ignored by Git. Supply your own trusted
copies outside the integration directory; see
[installation and licensing](../../../doc/local-model-adapters.md).
